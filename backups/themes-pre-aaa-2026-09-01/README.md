# Pre-AAA theme backup

These are byte-for-byte copies of the theme sources before the AAA redesign:

- `src/styles.css` — palette tokens and component styling
- `src/main.jsx` — theme catalog and descriptions
- `server/theme-contrast.mjs` — original contrast helper

To restore the original theme system, copy the backed-up files over their matching project paths. The SHA-256 hashes recorded at backup time matched each original exactly.
