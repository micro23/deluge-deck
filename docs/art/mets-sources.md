# New York Mets artwork

The Mets theme uses a separate visual composition: blue enamel cards, orange trim, an illuminated cap badge, Queens skyline, Home Run Apple details, and a brick stadium exterior at blue hour. The torrent list remains opaque.

- Official cap logo: [MLB team asset](https://www.mlbstatic.com/team-logos/121.svg), saved locally as `src/assets/sports/mets-logo.svg`.
- Original generated background: `src/assets/sports/mets-stadium.webp` (1600 × 900). Generated with the built-in ImageGen tool; [exact prompt and generation mode](mets-prompts.json) are preserved.
- Venue inspiration: the [Mets ballpark guide](https://www.mlb.com/mets/ballpark/information/guide), [Home Run Apple history](https://www.mlb.com/news/mets-home-run-apple-history), and [Jackie Robinson Rotunda background](https://www.mlb.com/news/wilpons-reflect-on-jackie-robinson-rotunda). The backdrop is an architectural illustration inspired by Citi Field, not a documentary photograph or exact reconstruction.
- Skyline, bridge, and Apple decorations are code-native SVG. The custom italic Mets text is interface typography, not a reproduction of the official script wordmark.
- The gallery thumbnail is captured from the working fictional demo interface.

Team names and marks belong to their respective owners. This is an independent fan theme with no team affiliation or endorsement. Assets are served locally without a third-party request when selecting the theme.
